## 🚀 Projects

### ✅ TaskPilot — Task Manager  
📍 [Live Demo](https://taskpilot-red.vercel.app/)  
🛠 Tech Stack: React · TailwindCSS · LocalStorage  

**Overview:**  
TaskPilot is a lightweight, efficient task management app designed to help users stay organized and productive. It includes the ability to add, edit, complete, and delete tasks with a minimal and responsive UI.

**🔎 Features:**
- Add new tasks
- Mark tasks as complete
- Delete or edit tasks
- Fully responsive design
- Local storage persistence (no backend needed)

### 💰 ExpenseTracker — Budget Management  
📍 [Live Demo](https://expensetracker-chi-seven.vercel.app/)  
🛠 Tech Stack: React · CSS Modules · Context API  

**Overview:**  
ExpenseTracker is a simple and effective way to monitor your personal spending. Users can track income and expenses, view their balance, and see categorized transaction history — all in one place.

**🔎 Features:**
- Add income or expense transactions
- Real-time balance updates
- Transaction history list
- Context-based state management
- Clean and modern interface
